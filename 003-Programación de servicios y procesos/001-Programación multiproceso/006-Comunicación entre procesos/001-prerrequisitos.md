Para trabajar en C/C++ se requieren dos cosas
1.-Un editor de texto el que queráis
2.-Un compilador

En Ubuntu:
Dos compiladores:
gcc para C
g++ para C++
Ya vienen preinstalados

En Windows:
1.-Hay que instalar los compiladores
2.-Recomiendo para ello MinGW: https://sourceforge.net/projects/mingw/
3.-Despues tenéis que añadir el ejecutable al Path del sistema

En resumen: VAMOS A TODOS A UBUNTU
